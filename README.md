# InovaFit 
O projeto consiste no desenvolvimento de um sistema de banco de dados para administrar uma academia.  O sistema será responsável pelo controle de:
- alunos;
- professores; 
- planos;
- matrículas;
- mensalidades;
- pagamentos;
- modalidades;
- turmas;
- inscrições;
- frequências;
- avaliações físicas;
- histórico de alterações das matrículas.

As regras mais importantes serão implementadas diretamente no banco de dados por meio de:
- chaves primárias e estrangeiras;
- constraints;
- procedures;
- trigger;
- transações;
- índices;
- testes automatizados.

A proposta atende à exigência de trabalhar com um problema identificável, regras de negócio reais e operações nas quais a lógica implementada no banco faça diferença. O documento alerta que um sistema que apenas realiza cadastros e listagens não é suficiente.
